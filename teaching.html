Teaching & learning

Teaching

Computer science education grounded in conceptual clarity, practical skills and project-based learning.

Programming languages

C, C++, Python, PHP and Assembly language fundamentals.

Systems and platforms

Linux, operating systems, server administration and computing environments.

Networking and architecture

TCP/IP, digital computer fundamentals, microprocessors and computer architecture.

Software and web technologies

Software engineering, HTML, CSS, WordPress and database technologies.

Learning approach

  • Connect core concepts with laboratory exercises and demonstrations.
  • Encourage students to build small working applications and document their process.
  • Use team-based activities to develop communication, leadership and problem-solving.
  • Relate computing topics to practical applications and current industry needs.

Student project ideas

Suggested project areas include Python applications, database-driven web systems, Linux administration, networking utilities, and renewable-energy monitoring concepts.
